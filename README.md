# Observatorio Mundial del Parking · ParkFacil

Portal de noticias internacionales de estacionamientos con archivo histórico y enlaces a fuentes.

## Publicación

En Settings → Pages seleccionar Deploy from a branch, rama `main`, directorio `/docs`.

En Actions → Actualizar observatorio → Run workflow ejecutar la primera actualización.

## Programación

Se programa alrededor de las 08:30 de Chile, con conversión automática de horario de verano. GitHub Actions puede ejecutar con retraso.

## Fuentes

Titulares de Google News RSS; fechas de publicación según el feed. Primera versión sin análisis de IA. Los artículos y sus fechas no están verificados independientemente.
